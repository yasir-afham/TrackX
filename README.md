# TrackX – iOS Expense Tracker

A native iOS expense tracking app built with Swift 6 and SwiftUI, featuring income/expense logging, spending charts, transaction filtering, Face ID/Touch ID app lock, and a home screen widget showing a live income/expense summary.

## About This Project

This app was built by closely following Kavsoft's SwiftUI Expense Tracker tutorial series to learn advanced SwiftUI patterns, state management, and WidgetKit. All code was written independently while following the tutorial, then extended with a home screen widget (via WidgetKit) showing real-time income/expense totals.

Tutorial reference: [Kavsoft – SwiftUI Expense Tracker](https://www.youtube.com/watch?v=vTmeKxEVY4A)

## Features

- Add and track income and expense transactions
- Category-based transaction organization
- Spending visualization with bar charts
- Filter and search transactions
- Face ID / Touch ID app lock for privacy
- Home screen widget (WidgetKit) showing live income/expense summary
- Built entirely with native Swift/SwiftUI — zero third-party dependencies

## Tech Stack

- **Language:** Swift 6
- **UI Framework:** SwiftUI
- **Widget:** WidgetKit
- **Architecture:** MVVM
- **State Management:** `@State`, `@ObservedObject`
- **Target Platform:** iOS 15+
- **IDE:** Xcode 15+

## Getting Started

1. Clone this repository
2. Open `TrackX.xcodeproj` in Xcode (15+ recommended)
3. Select a simulator or connected iOS device
4. Build and run (`Cmd + R`)
